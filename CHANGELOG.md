# Changelog

All notable changes to the Navigation Tabs web part will be documented in this file.

## [1.0.0] - 2026-03-10

### Added

- Tabbed category navigation with automatic grouping by Category field
- Three layout options: Card Grid, Compact List, and Tiles
- Built-in List Generator to create pre-configured SharePoint lists from the property pane
- Drag-and-drop tab reordering in the property pane
- Custom icon support via SharePoint Image/Thumbnail column
- Automatic click count tracking per link
- Active/Inactive toggle to hide links without deleting them
- Per-link new tab override control
- Configurable grid columns (2-6) for Card and Tile layouts
- SharePoint Online, Teams tab, and Teams personal app support
- PnPjs v4 for SharePoint data access
- Fluent UI React components for consistent SharePoint look and feel
