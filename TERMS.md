## Description of Service

Navigation Tabs is a SharePoint Framework (SPFx) web part that displays navigation links from a SharePoint list organized by categories. The Solution provides:

- Three layout styles (Card Grid, Compact List, Tiles)
- Built-in list generator for creating compatible SharePoint lists
- Drag-and-drop tab ordering
- Click tracking analytics
- Support for SharePoint pages, Teams tabs, and Teams personal apps

## Requirements

- SharePoint Framework compatible environment
- Appropriate SharePoint permissions to add web parts and create lists
